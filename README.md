# 手習い帖（app-20261107-tenarai）

**読めるのに書けない漢字を、習字帳の升目に指で書き、お手本を薄墨で重ねて自分の目で見比べる、大人のための書き取りの稽古帖。** iOS（SwiftUI）。enludus-daily の毎日のアプリ（2026-11-07、Bundle ID `com.enludus.daily.005`）。

## だれの・どう使うか
- スマホとキーボードで字を書かなくなった大人。手紙・一筆箋・申込書・ホワイトボードの前で「憂鬱」「曖昧」「挨拶」の手が止まる人
- 毎日 10 字（5〜20）：例文の空欄の「よみ」を見る → 升目に書く → お手本を重ねる → 書けた（はなまる）／惜しい（△）／書けなかった（・）を自分でつける
- 書けなかった字は明日、書けた字は 1・3・7・14・30・60 日あけて戻る。7 日あけて書けたら「書ける字」
- 書いた字は自分の筆跡のまま「手習い帖」に綴じられる。稽古の暦、続けた日数、苦手、束の進み具合。今日の一枚を画像で共有

## 既存との違い・長く使える価値
- 違い：自動の判定をしない（既存アプリのレビューで一番多い不満は誤判定）。自分の字の上にお手本を重ねて見比べる。書いた字そのものが帖に残る
- 価値：忘れかけた字が間隔をあけて戻るので、続けるほど書ける字が増え、自分の字の上達も帖で見返せる

## 作らなかったもの
手書きの自動認識・判定、筆順のアニメーション、漢検の級の網羅、広告、アカウント・同期、Apple Intelligence（決まった計算で十分）

## 世界観（app-quality-bar look.md §1）
- 棚卸し：半紙・習字帳の升目（十字の補助線）・文鎮・墨と薄墨・朱の添削（はなまる）・和綴じの帖・下敷き・筆・硯・お手本
- **このアプリでは、習字帳の升目と半紙が稽古の画面に、和綴じの帖が記録の画面になる**
- 部品（`App/Sources/Parts.swift`）：`GridCell`（十字の点線の補助線つきの升目）、`Hanshi`（固定の乱数で描く半紙の繊維）、`Bunchin`（文鎮）、`Hanamaru`（渦＋8 枚の花びら。trim で描かれる）、`Sankaku`（△）、`TojiBinding`（和綴じの穴と糸）、`PageGutter`（Duo の見開きの綴じ目）

## トークン（`Theme.swift`）
- 色は藤の 1 系統：fuji `#C9BFEA`（L0.83）／soft `#ECE8F7`／deep `#7568A8`（白文字のボタンと小さな文字だけ）／paper `#FBFAFC`／糸 `#B9AEDD`。地 `#F3F2F7`、墨 `#2E2C3A`、補助 `#8C8A99`、線 `#E2DFEB`
- 差し色ははなまるの peach `#F4BBA4`／`#D9957A` だけ（小さな印）
- 暦の濃さは書いた字の数の区切り（0／1〜4／5〜9／10 以上）で 4 段階。段（0〜6）は点の数、書ける字になると deep
- 見出し・数字・字はセリフ（ヒラギノ明朝）、大きな数字は字間を詰める（-1〜-3）、小さなラベルは開ける（0.6）
- 角丸 6／12／14／18（continuous）、影は普段 0.06・r10・y4、今日の一枚だけ 0.14・r8・y6
- ライトに固定（半紙と墨の世界観。StudyReel と同じ判断）
- `python3 scripts/tone-check.py`：exit 0（強い色 0 件）

## 手応えの表（feel.md）
| できごと | 動き | 振動 | 音 |
|---|---|---|---|
| 押す（升目に書く） | 線がその場で引かれ、書いている升目の枠が藤色になる。ボタンは 0.96〜0.97 倍に沈む | なし（1 画ごとに鳴らすと多すぎる） | なし |
| お手本と見比べる | お手本が薄墨で 1.04 倍から重なる（easeOut 0.35）、よみと束の名が出る | `.selection` | なし |
| 1 つ成功（書けた） | はなまるが升目の右上に描かれる（trim 0→1・0.5 秒・-6°） | `.success` | なし |
| 惜しい | △ が描かれる | `.impact(.light)` | なし |
| 失敗（書けなかった） | 升目が小さく横に揺れる（5pt の減衰・0.35 秒）、・が付く | `.warning` | なし |
| 連続 | 3 字続けて書けたら「n 連続」の札が出る（scale 0.9 から） | 成功と同じ（連続で強めない） | なし |
| 次の字へ（場面の切れ目） | ページをめくるように右から入り左へ出る | なし | なし |
| 完了（今日の分） | 今日の一枚が少し傾いて置かれる（-4°→-1.2°、spring 0.45/0.85）、数字は numericText | 最後の丸の `.success` | なし |

音は入れない：静かに字を書く稽古なので、消音の場所（電車・職場）でも使えることを優先。動きを減らす設定では、揺れ・めくり・はなまるの描画・使い方の動く見本を止める。振動は設定で切れる。

- 状態：初回（使い方 3 ページ・動く見本）、今日の分なし、今日の分おしまい、帖が空、苦手なし、書ける字なし、筆跡が残っていない字、Pro の鍵、購入できない（読み込み失敗）、読み込み中、通知の許可なし（設定を開く）

## iPhone Duo
並べ方は size class だけで決める（機種・向き・画面の大きさでは決めない）。内側（regular）：稽古は見開き（左に例文、右に半紙と大きな升目、間に綴じ目）、四字熟語も 1 行の 4 マス。帖は左に暦と束、右に字の一覧。外側・ほかの iPhone：縦に重ね、3〜4 字は 2 列に折り返す。書いた線は升目ごとの座標で持つので、開け閉めで並びが変わっても字は崩れない。出典：Apple Tech Talk「Prepare your app for iPhone Duo」https://developer.apple.com/videos/play/tech-talks/111461/

## 課金
